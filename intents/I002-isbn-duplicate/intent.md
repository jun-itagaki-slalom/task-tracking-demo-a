# インテントの記録：本の登録で ISBN の重複を防ぐ

| 項目 | 内容 |
|---|---|
| インテント ID | I002 |
| インテントの Issue | #25 |
| 始める局面 | 要件定義（F01 の要件を変える） |
| 承認 | PdM（PR で承認） |

## なぜ（Why）

同じ本が一覧に 2 件出て、貸し出しの記録が分かれてしまう。

## 何を基準にしたか（Baseline）

- F01 の要件（`specs/library/features/F01-book-register/requirements.md`）。US-1 は I001 で完了済み

## 何をどう変えるか（Delta）

- 変更：F01 US-1 の受入シナリオに「同じ ISBN の本は登録できない」を足す

## 影響する機能（Impact）

- F01（本の登録）。F02（貸し出し）は本の ID で本を見るため影響しない

## 変えない振る舞い

- 題名・著者・ISBN を入れて登録すると、本の一覧に出る
