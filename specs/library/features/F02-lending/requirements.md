# 要件仕様：貸し出し

| 項目 | 内容 |
|---|---|
| 機能 ID | F02 |
| 機能名 | 貸し出し |
| 承認 | PdM（PR で承認） |

## 1. 概要

利用者が本を借り、返し、返す期限を延ばせるようにする。

## 2. ユーザーストーリー

- **US-1（優先度 P1）**：利用者は、本を借りたい。なぜなら、家で読みたいから。
  - 受入シナリオ：貸し出せる本を選んで借りると、その本は貸し出し中になり、返す期限が出る
- **US-2（優先度 P1）**：利用者は、借りた本を返したい。なぜなら、次の人が借りられるようにしたいから。
  - 受入シナリオ：借りた本を返すと、その本は貸し出せる状態に戻る
- **US-3（優先度 P2）**：利用者は、返す期限を延ばしたい。なぜなら、読み終わらないことがあるから。
  - 受入シナリオ：期限の前に延長すると、返す期限が 2 週間延びる

## 3. 機能要件

- **FR-1**（US-1）：システムは、利用者と本を受け取って貸し出しを記録しなければならない。
- **FR-2**（US-2）：システムは、返却を記録し、本を貸し出せる状態に戻さなければならない。
- **FR-3**（US-3）：システムは、期限の前の延長を受け付け、返す期限を 2 週間延ばさなければならない。

## 7. 受入基準

- 借りると、本が貸し出し中になり、返す期限が出る
- 返すと、本が貸し出せる状態に戻る
- 期限の前に延長すると、返す期限が 2 週間延びる
