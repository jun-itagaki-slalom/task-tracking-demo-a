# 要件仕様：本の登録

| 項目 | 内容 |
|---|---|
| 機能 ID | F01 |
| 機能名 | 本の登録 |
| 承認 | PdM（PR で承認） |

## 1. 概要

図書係が本を登録し、利用者が本を探せるようにする。

## 2. ユーザーストーリー

- **US-1（優先度 P1）**：図書係は、題名・著者・ISBN を入れて本を登録したい。なぜなら、貸し出せる本を一覧で管理したいから。
  - 受入シナリオ：題名・著者・ISBN を入れて登録すると、本の一覧に出る
- **US-2（優先度 P2）**：利用者は、題名か著者で本を探したい。なぜなら、借りたい本をすぐ見つけたいから。
  - 受入シナリオ：題名の一部を入れて探すと、合う本だけが一覧に出る

## 3. 機能要件

- **FR-1**（US-1）：システムは、題名・著者・ISBN を受け取って本を登録しなければならない。
- **FR-2**（US-2）：システムは、題名か著者の一部で本を探せなければならない。

## 7. 受入基準

- 題名・著者・ISBN を入れて登録すると、本の一覧に出る
- 題名の一部で探すと、合う本だけが出る
